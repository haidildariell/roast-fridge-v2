Entry for the make.fun bounty [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521). One single roast line: a fridge that hums all night like it pays rent, guarding a jar of pickles older than the owner's last relationship under a bulb that judges at 2 a.m. — specific, visual, and the sting lands on the last words.

## Run

```bash
python3 main.py
```

The program writes the single roast line to `entry.txt` inside the output directory (`OUTPUT_DIR` env var when set, otherwise `/output`).
